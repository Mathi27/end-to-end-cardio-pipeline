# BITS Group 120 | MLops

## Heart Disease Risk Prediction: End-to-End MLOps System

## Project Overview

This project implements a production-grade machine learning system designed to predict the risk of heart disease based on patient health data. 

It moves beyond a simple modeling exercise to provide a scalable, reproducible, and automated ML solution following modern MLOps best practices.

## Objective

- To design, develop, and deploy an end-to-end ML solution that mirrors real-world production scenarios. The system emphasizes:

- Practical Automation: Data and modeling pipelines.

- Experiment Tracking: Systematic logging of parameters and metrics.

- CI/CD Pipelines: Automated testing and deployment.

- Containerization: Environment consistency across development and production.

- Cloud Deployment: Scalable hosting.

- Monitoring: Real-time tracking of model performance and data drift.
